AsterLab Tools

把常用工具产品，做成一个能直接上 GitHub Pages 的前端工作台。

一个静态站，集成开发、文档、图片、PDF、设计、效率、排班、简历、报价单和生活计算器。 默认本地优先，适合个人项目、作品集与独立工具站。

工具模块 18
部署方式 纯静态 / GitHub Pages
运行逻辑 浏览器本地优先

站点能力

  • 开发工具箱：JSON、YAML、CSV、正则、哈希、JWT、时间戳
  • 内容工作台：Markdown、文本清洗、标题优化、敏感词提示
  • 设计工具：配色、渐变、阴影、海报生成、流程图预览
  • 业务效率：简历、报价单、记账预算、番茄钟、排班生成
本地存储 收藏与工作状态
导出方式 HTML / TXT / JSON / PDF / PNG
