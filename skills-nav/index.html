局域网传书到 Kindle

整理自本地项目 F:\\codex\\kindle-share，当前是一个本地服务，不是公网网站。

怎么用

  1. Windows 里双击 start_kindle_share.bat，或者在目录里运行 python run.py。
  2. 电脑页面上传一本书，系统会生成一个 6 位取书码。
  3. Kindle 在同一局域网里打开取书页，输入取书码并下载。
  4. 下载成功后文件立即删除；如果一直没人取，也会在超时后自动清掉。

地址与参数

  • / 电脑上传页
  • /kindle Kindle 取书页
  • /health 服务状态检查
  • --port 9000 改端口
  • --ttl-minutes 10 改自动清理时间

支持格式

.azw .azw3 .epub .kfx .mobi .pdf .prc .txt

部署方式

  • 本地直接跑，默认端口 8866。
  • 也可以用项目自带 Dockerfile 部署到服务器。
  • 如果要外网访问，需要自己再接反向代理和域名。
